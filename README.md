# 自在江湖复刻项目

本项目目标是对用户指定的 7k7k 平台游戏《自在江湖》进行 1:1 复刻，逐项核对视觉、交互、规则与状态，并通过接口测试与内部浏览器页面点击测试双重验收。

- 参考入口：https://h5.7k7k.com/
- 本地目录：`D:\work\hd\game-zizaijianghu`
- 远程仓库：https://github.com/linGuangFeng/game-zizaijianghu

## 当前状态

已提供可运行的本地角色创建与存档基础：选择男/女参考、输入姓名、保存和刷新恢复，并进入江湖导航容器，往返角色资料和已实现武学页面。它尚不是可游玩的完整游戏，缺少原版独立美术资源、主场景、战斗、剧情与后续系统。

另有只读武学图鉴，以及显式开发检查点下的单双武学一键装配、指定槽位卸下及双武学手动卡片装卸（槽位、卡片与任务同步保存，卸下不清除已完成任务）。检查点启动方法见 [本地接口](docs/local-api.md)，不是默认给所有新角色发放技能。装配、卸下均已通过独立接口及内部浏览器点击测试。

显式三本样本新增中槽卸下、补回和固定顺序一键装配，保留旧存档；不默认授予第三本。该增量页面尚未验收，不能沿用单双武学的页面通过结论。详见 [三槽证据](docs/third-martial-evidence.md)。

武学装卸结果未确认时会锁定操作，重新读取成功后恢复；图鉴忽略过期响应，锁槽支持查看已记录的条件提示。这些增量的 HTTP／客户端脚本回归不代替内置浏览器页面验收。

原版已进入推荐服，采集创角、剧情、双武学装卸及事件2实际战斗/胜利展示；断线重连后角色与首个任务进度保留。完整页面、玩法、数值、资源与交互仍待调查，不能宣称完整 1:1 已实现。

## 技术方案

当前基础采用原生 HTML/CSS/JavaScript 与 Node.js 22，无第三方依赖。完整游戏的渲染引擎仍待资源与场景取证后确定。

本地已核实环境：

| 工具 | 版本 |
| --- | --- |
| Node.js | v22.17.0 |
| npm | 10.9.2 |
| Git | 2.50.0.windows.2 |

## 开发与验证要求

- 按已核实的原版行为实现，区分已证实信息、推断与待确认项。
- 多代理分工实施，由主会话协调进度、依赖与验收。
- 测试同时覆盖接口状态变化和内部浏览器页面点击流程。
- 浏览器操作使用内部浏览器，不启动宿主机浏览器。
- 本地固定¥6测试商品支持直接成功订单与首日奖励，详见 [测试购买验收](docs/test-commerce-qa.md)；完整充值系统尚未实现。
- 不将登录凭据、会话信息、密钥或真实支付数据提交到仓库。

## 启动与测试

在仓库根目录运行 `npm.cmd start`，访问 `http://127.0.0.1:3000/`。存档默认位于 Git 忽略的 `.local/character.json`；不需要原站账号。运行 `npm.cmd test` 执行服务端测试。

接口及隔离运行说明见 [本地接口](docs/local-api.md)，当前视觉缺口见 [客户端基础](docs/client-foundation.md)，独立验收见 [本地基础验收](docs/local-foundation-qa.md)。
