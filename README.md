# 自在江湖复刻项目

本项目目标是对用户指定的 7k7k 平台游戏《自在江湖》进行 1:1 复刻，逐项核对视觉、交互、规则与状态，并通过接口测试与内部浏览器页面点击测试双重验收。

- 参考入口：https://h5.7k7k.com/
- 本地目录：`D:\work\hd\game-zizaijianghu`
- 远程仓库：https://github.com/linGuangFeng/game-zizaijianghu

## 当前状态

仓库已从用户指定的空远程仓库克隆。目前处于原版取证与需求确认阶段，尚未实现游戏、服务端或启动脚本，不能启动或游玩。

尚未核实原版完整页面、玩法、数值、资源与交互，因此当前不能确认复刻范围或宣称功能已经完成。当前平台已登录，用户已同意游戏协议，已采集 Unity WebGL 选服页，尚未进入推荐服。

## 技术方案

候选技术栈为 TypeScript 客户端与 Node.js 服务端。渲染方式、客户端框架、存储方案及依赖版本将在取得原版证据后确定。

本地已核实环境：

| 工具 | 版本 |
| --- | --- |
| Node.js | v22.17.0 |
| npm | 10.9.2 |
| Git | 2.50.0.windows.2 |

## 开发与验证要求

- 按已核实的原版行为实现，区分已证实信息、推断与待确认项。
- 多代理分工实施，由主会话协调进度、依赖与验收。
- 测试同时覆盖接口状态变化和内部浏览器页面点击流程。
- 浏览器操作使用内部浏览器，不启动宿主机浏览器。
- 充值在测试环境中使用直接成功的模拟流程；支付能力尚未实现。
- 不将登录凭据、会话信息、密钥或真实支付数据提交到仓库。

启动命令、测试命令和实际实现范围将在对应功能完成并验证后补充。
