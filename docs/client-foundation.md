# 客户端基础：角色创建与恢复

这是 Codex 在本地编写的原生 HTML/CSS/JavaScript 基础，不是 Grok 产物。入口为 `client/index.html`，由 Node HTTP 服务同源托管。无第三方客户端依赖，无宿主机浏览器操作。

## 启动与交互

在仓库根目录执行 `npm start`，默认访问 `http://127.0.0.1:3000/`。服务端文件与命令由架构代理维护；需主代理或测试代理使用内部浏览器完成页面验收。

无存档时：点击“男”或“女” → “下一步” → 在“角色名称”输入框填写姓名 → “保存角色”。页面进入江湖容器并显示已保存名称及性别。刷新重新读取服务端同一角色。已有存档时同样进入江湖，不提供删除、重建或未知游戏入口。

“返回”保留本次输入，返回性别选择；保存中锁定输入与按钮，失败时保留用户输入并允许重试；初次读取失败可点“重新读取”。姓名按用户输入原样提交，不猜测原站生成、长度、字符或重名规则。

## 本地接口契约

- `GET /api/appearance-options`：`{options:[{id,label,evidence}]}`。当前仅 `male-reference-0002` 与 `female-reference-0003`，页面显示男/女。
- `GET /api/character`：成功为 `{character:{name,appearanceId}}`；404 表示没有存档，进入创建。
- `PUT /api/character`：提交 `{name,appearanceId}`，成功返回 `{character:{name,appearanceId}}`。

以上是本项目自定义基础接口，不声称复现原版通信协议。客户端不使用 localStorage 假装服务端保存；保存/恢复实际请求同源服务。

## 视觉与范围限制

布局参考已取证竖屏、性别选择与姓名两步，但原版独立立绘、场景、图标、字体和动画资产尚缺。当前使用纯色背景、文字标记与基础控件，未把整张截图充当交互界面，也未冒充原版美术。页面只显示当前可用流程，不铺技术说明。

未实现发型、服饰、原版随机姓名、原版姓名校验、战斗、剧情、主场景、充值或多人。江湖中央仍为中性占位，“我的角色”为侠客资料面板，不是原版完整主场景。不能据此宣称 1:1 已实现。

客户端语法可用 `node --check client/app.js` 核验。内部浏览器的点击创建、刷新恢复与接口持久化验证由主代理安排的测试代理执行；本客户端代理未操作浏览器，不把静态检查当作页面验收。

详情按接口提供的片段逐条呈现，截断说明及不完整天赋标“未完整收录”，不将片段拼成声称完整的规则。等级、星级、属性和锁为参考记录，页面以“参考资料 · 只读”标识。无技能立绘、原版界面截图铺屏或虚构战斗效果；尚不构成原版武学系统的 1:1 实现。客户端代理仅进行语法核验，主代理负责内部浏览器的图鉴导航与存档不变检查。

## 增量：显式检查点一键装配

服务端仅在已存在角色且启动配置 `MARTIAL_CHECKPOINT=observed-before-equip` 时初始化已观测检查点；具体存储/启动规则见服务端文档。客户端读取 `GET /api/martial-state`：404 时保留原有角色与图鉴，200 `{state}` 时显示“武学”入口及装配任务，409 显示角色与武学记录不匹配，不重置记录。

进入“武学”显示服务端返回的六槽、已拥有上勾拳及任务。点击“一键装配”发送 `POST /api/martial-state/auto-equip`（无正文），收到成功 `{state}` 后更新槽位 1、已装配标记和任务 1/1。失败只显示错误，不自行修改槽位或任务。返回角色再进武学重新读取，刷新也从服务端恢复。任务显示使用 `state.task.current/target`，不由槽位是否非空推导。

已补充已观测的编辑与槽位 1 卸下（见下节）；仍没有拖动、升级、升星或解锁操作。装配页以独立 DOM/CSS 排列参考原版的错落六槽、拥有卡片及底部操作，没有整图铺屏，独立角色/技能美术仍缺。检查点是测试入口而非所有新角色的默认值；只读图鉴仍保持 GET 与只读内容。

## 增量：编辑与卸下

单武学检查点 `observed-before-equip` 的武学页点击“编辑”，已装配的槽位 1 右上出现红叉按钮，可访问名称为“卸下上勾拳”；点击立即发送 `POST /api/martial-state/unequip`（无正文），无额外确认弹框。成功后仅依据响应 `{state}` 重画槽位、拥有卡片及任务；已完成的任务继续显示服务器返回的 1/1，不因空槽重置。点击“退出编辑”隐藏红叉；返回角色再进武学从普通查看状态开始。

保存期间禁用装配、编辑、卸下及返回，失败保留已有槽位/任务并显示重试提示。此行为保护本地操作一致性，不声称原版也采用相同防重实现。只对已取证的槽位 1 提供卸下，未加入拖动排序、换位或点击空槽装配。原版图像素材仍缺，红叉与槽位是独立 CSS/DOM 实现，没有使用整屏截图冒充交互。

验证：脚本语法和变更空白检查通过；页面点击与服务端失败路径由主代理/QA 验收，本代理未使用浏览器。
