1. 原版采集：内部浏览器打开准确入口，完成登录；记录渠道、服务器、角色初始状态、页面结构、可见按钮与点击后状态。记录截图和去敏后的接口证据。尚未解锁或不可访问系统标记未知。
2. 范围和契约：建立完整系统清单，关联原版证据、解锁条件、状态转移和验收用例；确定渲染方式、数据模型与接口。无法观察的规则列差异，不能自行宣称已还原。
3. 基础实现：实现已验证的首个完整操作闭环和持久化，再按已确认系统逐项扩展。接口与页面同步交付，禁止仅用静态展示替代操作。
4. 支付与长流程：实现本地测试支付成功、奖励与重复通知处理；对已确认系统做刷新、重启和连续操作验证。
5. 独立验收：测试代理逐项执行接口与真实点击用例，主会话审核证据并分派缺陷，修复后复测。
6. 完整性核验与交付：核对原版范围、实现和双层验收，无缺项才能对已核实范围标记完成；明确剩余不可核实部分。构建、启动说明和通过证据齐备后推送用户仓库。
