# 本地基础服务独立验收准备

更新：2026-10-13（Australia/Perth）。执行角色：本地 Codex QA 代理。本文不是 Grok 输出，也不是 Grok 独立测试结果。Grok 调用审批阻塞不通过本任务绕过。

## 范围与依据

依据 `character-creation-spec.md` 及 `test-plan.md`，准备验收本地 Node.js 基础服务的健康、独立存档及读取能力。服务端由 repo_architect 实施；本地自定义契约不代表原版接口或业务规则。准备阶段尚无接口文档；实际执行前已读取 `local-api.md` 并核对实现，按 GET /api/health、GET /api/appearance-options、GET/PUT /api/character 绑定下列用例。

当前 LF-API-01 至 08 已由本地 QA 代理实际独立执行并通过；页面 LF-UI-01 至 04 依据主聊天实际内部浏览器执行报告记录通过，LF-UI-05 仍阻塞。两类执行归属及证据分别列在下文。本代理未运行浏览器或 Grok，未采信开发者自测代替独立执行。

## 原版事实及状态差异

原版已有男女外观、服饰页、角色名称页、创建后首屏及首次剧情证据；主代理报告点击生成名后的下一步进入首屏。主聊天后续已报告原版重登后角色及任务 1/1 保留，证据为 `evidence/original-reconnect-scene.jpg`；这不说明已掌握原版后端保存规则。本地存档可靠性可以独立测试，但通过仅说明本地契约成立，不能声称已还原原版保存规则。

准备阶段发现的总测试计划旧进服状态已由主代理修正；本代理未修改共享计划或矩阵。

## 执行前置条件

- 架构代理交付本地 API 契约、启动和停止方式、健康响应、存档格式、读取身份及错误行为。
- 确认可指定独立测试数据目录和未占用端口；记录代码提交与工作区变更。不得覆盖人工测试角色或正式数据。
- 采用两份互异测试数据 A、B，具体字段按契约确定；使用测试中文文本核对编码，不把样例姓名固定为原版默认。
- 确认本地服务就绪后再执行；只终止本次测试创建并记录的服务进程。保留独立测试目录及日志证据，不清理无关目录。
- 若契约不支持某能力，明确标不适用或缺口并说明原因，不能擅自增加接口或测试假设。

## 页面与接口联动用例

页面执行由主聊天负责；主聊天使用独立的 3000/3001 端口与浏览器 QA 存档，本代理的接口测试使用系统分配端口及另一组专用目录。数据集相互独立，按相同契约交叉核对，不能把两个角色混记为同一份存档。

| 编号 | 主聊天真实点击步骤 | 接口交叉验证与预期 | 当前缺口及状态 |
| --- | --- | --- | --- |
| LF-UI-01 | 打开实际本地入口，按已实现的保存操作输入测试状态并点击保存 | 独立读取接口取得该次页面提交的状态；页面成功提示与结果一致 | 主聊天真实保存后页面、API、磁盘同值；PASS |
| LF-UI-02 | 页面保存后刷新并进入同一状态页 | 页面读取值与接口一致；不得以浏览器缓存掩盖未保存 | 主聊天刷新后显示已读取角色；PASS |
| LF-UI-03 | 页面保存后重启本地服务，再在内部浏览器刷新读取 | 页面与重启后接口结果一致 | 主聊天重启 3000 后刷新仍为清风测试/男；PASS |
| LF-UI-04 | 若实际页面提供保存错误反馈，制造契约允许的失败后点击保存 | 页面不能显示假成功；接口读取最后有效状态 | 主聊天断服保存失败未落盘，恢复后同页面重试成功；PASS |
| LF-UI-05 | 当创角客户端实现后，真实点击外观选择、下一步与名称页提交 | 对照已确认的原版步骤，并读取本地保存内容；未知字段及规则单列，不补编 | 当前为本地基础交互，尚非原版完整创角与画面；BLOCKED |

本地调试表单即使完成 LF-UI-01 至 04，也只证明基础联动；它不是原版创角画面，不能替代 1:1 视觉、动画或流程验收。LF-UI-05 必须使用真实实现的创角页面，不能通过调用 JavaScript 内部函数完成。

## 原版未知项与不覆盖范围

- 原版保存时点、角色标识及实际 HTTP 或 WebSocket 协议；已观察重登保留不等于已掌握全量持久化规则。
- 默认性别及外观、发型和服饰总数、切换或返回是否保留选择。
- 名称输入、生成按钮、长度、字符、重名规则；不凭中文示例推导限制。
- 创建防重、失败重试、网络异常行为；动画、音频及切换节奏。
- 首屏资源含义、初始数值、任务推进与奖励，底部各系统内部页面。
- 本地服务是否具备认证、多角色、多服或并发冲突规则，须以实际契约为准，不能把目录隔离等同于上述能力。
- 基础存档测试不覆盖充值；测试充值直接成功及权益发放需另行实现并按总测试计划验收。
